# isa-phm

Python wrapper for ISA-PHM datasets generated by ISA-PHM Wizard.

It provides:
- Parsing + preprocessing of ISA-JSON
- A fluent API for studies, assays, and runs
- CSV loading with strict/lenient malformed-line control
- Validation and semantic normalization utilities
- JSON-only tool interface for AI/agent integrations

## Install

```bash
pip install -e .
```

## Quick Start

```python
from isa_phm import ISAWrapper

wrapper = ISAWrapper(
    "path/to/i_investigation.json",
    data_root="path/to/data",
    strict_validation=False,
)

print(wrapper.investigation_overview())
print(wrapper.summary())

study = wrapper.study("Case 01")
assay = study.assay("a_st01_se01")
df, meta = assay.load_dataframe_with_meta(file_type="auto")
print(meta.model_dump())
```

## Public API Highlights

- Core navigation:
  - `wrapper.study(...) -> StudyProxy`
  - `study.assay(...) -> AssayProxy`
  - `assay.run(...) -> RunProxy`
- Summaries:
  - `wrapper.summary()`
  - `wrapper.extensive_summary()`
  - `wrapper.contacts()`
  - `wrapper.publications()`
- Validation + semantics:
  - `wrapper.validate_dataset(...)`
  - `wrapper.semantic_manifest(...)`
  - `wrapper.ai_context(...)`
- AI tools (JSON-in/JSON-out):
  - `wrapper.list_tools()`
  - `wrapper.call_tool(name, args)`

## Data Loading Behavior

`DataIntegrator` supports:
- `file_type="processed" | "raw" | "auto"`
  - `auto` prefers processed, then raw.
- `csv_bad_lines="error" | "warn" | "skip"`
  - Default is `error` (strict, recommended).

`load_dataframe_with_meta()` returns `DataLoadMetadata` including resolved file source and CSV read diagnostics (engine, separator, encoding, detection source).
